CORE CONCEPTS TO IMPLEMENT
========================

A) FRAME STREAMING (Soft real-time)
- Use WebSockets for streaming “soft real-time” frames at 1 FPS (not video streaming).
- Each frame:
  - downscale to max width 512px (keep aspect ratio)
  - JPEG quality 0.4–0.6
  - send as base64 data URL
- Messages:
  Client -> Server:
    { type: "hello", userId }
    { type: "frame", userId, ts, imageDataUrl, mode }   // mode: "hazard" | "qa"
    { type: "question", userId, ts, text }
    { type: "set", userId, cloudEnabled, offlineSimulated } // toggles for demo
  Server -> Client:
    { type: "update", ts, routed, reason, confidence, hazards, say, speak, debug }

B) AGENTIC WORKFLOW (Local-first)
Implement a simple agent loop per user/session:
1) PERCEIVE: run local FunctionGemma inference (via Cactus adapter) to produce structured JSON:
   - labels/objects (coarse)
   - hazards list (stairs, dropoff, obstacle)
   - confidence score 0..1
   - short local “say” suggestion (<= 1 sentence)
2) ROUTE: decide whether to call Gemini
3) ACT: return final message (local or cloud) + speak gating

C) SMART HYBRID ROUTING (the judging centerpiece)
Implement a routing policy function (well-commented) that takes:
- offlineSimulated (UI toggle) OR actual connectivity signal from client
- cloudEnabled toggle
- mode ("hazard" or "qa")
- local confidence score
- a latency budget (hazard budget small, qa budget larger)
- lastCloudCallTs (rate limiting)
and returns:
- routed: "local" | "cloud"
- reason string

Routing rules (must implement):
1) If mode == "hazard" => ALWAYS LOCAL (latency + safety)
2) If offlineSimulated == true OR cloudEnabled == false => LOCAL
3) If confidence >= 0.75 => LOCAL
4) Else if last cloud call was < 5 seconds ago => LOCAL (avoid thrashing)
5) Else => CLOUD (Gemini)

Cloud fallback logic:
- If Gemini call errors or times out (>2.5s), return LOCAL fallback with safe phrasing.

D) SPEAK GATING (no spam)
Only speak when:
- hazard is high severity AND new (not seen in last ~3 seconds), OR
- user asked a question, OR
- last spoken was > 4 seconds ago AND message meaningfully changed
Store lastSpokenTs + lastSpokenHash per session.

E) HTTP FALLBACK (for demo safety)
Implement:
POST /frame
- body: { userId, ts, imageDataUrl, mode, cloudEnabled, offlineSimulated }
- returns same structure as WS update

POST /ask
- body: { userId, ts, text, cloudEnabled, offlineSimulated }
- uses last perceived state + routing; returns { routed, reason, say, speak:true }

Also implement:
GET /health => "ok"
